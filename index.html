Simple guide

How to use this roadmap

1. Start with the broad AI Engineer core in My roadmap. 2. Build the required projects and prove skills with the self-checks. 3. Activate one specialization focus when its readiness foundations are solid. 4. Use Full roadmap for recommended and optional depth related to AI Engineering.

What is “Full roadmap”?

It shows the complete AI Engineer map for the broad core plus your active specialization: required steps, projects, experience, recommended next depth and relevant optional/advanced topics. Unrelated careers are not included in this edition.

What does the link inside Details mean?

Open Details first. It now tells you whether the link is a course, certification exam, university self-study page, official documentation, book, project reference or professional framework; whether you need to enroll; and whether any certificate is optional. A linked provider is usually a learning resource, not automatically a required credential.

Can I skip a course I already know?

Yes. Open the step and use its suggested practical check. The roadmap cares about what you can do, not whether you repeated a specific course.

What should I do first?

Start with the AI Engineer core and click Next step. Add a specialization or optional focus only after the main path is moving well.
